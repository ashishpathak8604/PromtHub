🚀 PromptHub

A modern AI Prompt Marketplace & Discovery Platform built with React, Vite, Tailwind CSS, Framer Motion, and Clerk. PromptHub lets users discover, save, like, submit, and organize high-quality AI prompts through a clean and modern interface. 🤖✨

✨ Features
🔍 Discover and explore AI prompts
❤️ Like and 🔖 bookmark prompts
📝 Submit and manage your own prompts
📚 Curated prompt collections
👤 User profiles with prompts, likes & bookmarks
💡 Suggest improvements to existing prompts
📋 One-click prompt copying
🎨 Responsive modern UI with smooth animations
🔐 Authentication powered by Clerk
⚡ Built with React + Vite for a fast experience
🚀 Deployed on Vercel
🛠️ Tech Stack

React • Vite • Tailwind CSS • Framer Motion • Clerk • Lucide React • Vercel
